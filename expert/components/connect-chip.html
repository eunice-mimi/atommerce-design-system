Usage

아래는 네가 제공한 실제 활용 예시야. 기간 선택 옵션을 연결된 그룹으로 구성하고, 별도의 비교하기 Select/Dropdown과 함께 사용하는 형태가 확인돼.

Usage 이미지에서 확인되는 실제 예시는 “기간 직접 선택 / 이번 달 / 1개월 / 3개월 / 6개월 / 12개월” 형태입니다. 이 Usage 예시는 사용자가 제공한 화면 캡처를 기준으로만 설명했습니다.
