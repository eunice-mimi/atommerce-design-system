Form

Input · Checkbox · Button을 일관되게 조합하는 기본 입력 패턴입니다.

↗

HTML

<form class="form-stack">
  <label class="ds-field">...</label>
  <label class="ds-field">...</label>
  <label class="ds-check">...</label>
  <button class="atom-button atom-button--primary">신청하기</button>
</form>

CSS

.form-stack {
  display: flex;
  flex-direction: column;
  gap: 16px;
  width: 100%;
}
Design intent

디자인 의도

Input · Checkbox · Button을 일관되게 조합하는 기본 입력 패턴입니다.

Structure

구조 / Properties

CompositionInput + Checkbox + Button
Flow입력 → 검증 → 제출
Behavior관련 입력을 하나의 작업 단위로 구성
Design token

Design Token

정확한 토큰 값은 해당 컴포넌트의 Figma / Registry에 문서화된 값만 사용합니다.
Spacing

Spacing

Spacing은 문서화된 semantic spacing token을 우선 사용합니다. 정확한 값이 없는 경우 임의 값을 생성하지 않습니다.
Radius

Radius

Radius는 해당 컴포넌트에 정의된 semantic radius token을 사용합니다.
Typography

Typography

Typography는 UI 역할에 맞는 Component / Body / Title semantic style을 사용합니다.
Behavior

State / Behavior

Structure

  • Label → Field → Helper/Error 순서를 유지합니다.
  • 관련 field는 한 섹션으로 묶습니다.
  • 주요 제출 CTA는 폼 하단에 일관되게 배치합니다.
Accessibility

Accessibility

label, validation, error feedback, keyboard order를 유지합니다.

For AI

AI Guidance

Form은 Atommerce Input, Checkbox, Button component를 조합해서 만든다. 새로운 field style을 폼 안에서 따로 만들지 않는다. Validation message는 해당 field 가까이에 배치한다. 주요 제출 CTA hierarchy는 하나만 명확하게 둔다.
