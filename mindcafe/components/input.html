Design intent

디자인 의도

Figma Core library의 text-field를 기준으로 입력 컴포넌트의 기본 구조와 구현 코드를 정리합니다.

Structure

구조 / Properties

RoleLabel · Field · Helper / Error
StateDefault · Focus · Error · Disabled
Behavior입력값과 상태 메시지를 함께 관리
Design token

Design Token

정확한 토큰 값은 해당 컴포넌트의 Figma / Registry에 문서화된 값만 사용합니다.
Spacing

Spacing

Spacing은 문서화된 semantic spacing token을 우선 사용합니다. 정확한 값이 없는 경우 임의 값을 생성하지 않습니다.
Radius

Radius

Radius는 해당 컴포넌트에 정의된 semantic radius token을 사용합니다.
Typography

Typography

Typography는 UI 역할에 맞는 Component / Body / Title semantic style을 사용합니다.
Behavior

State / Behavior

  • Label은 입력값의 목적을 명확하게 설명합니다.
  • Placeholder는 예시나 입력 형식을 보조할 때만 사용합니다.
  • Error는 border와 helper message를 함께 노출합니다.
  • Disabled는 사용자가 수정할 수 없는 상태에만 사용합니다.
Accessibility

Accessibility

label과 input을 연결하고 helper/error 메시지가 입력 필드와 함께 해석되도록 합니다.

For AI

AI Guidance

Atommerce Core Design System의 text-field를 사용한다. Label / input / helper text 구조를 유지한다. Error는 색상만 바꾸지 말고 error helper message도 함께 제공한다. semantic token을 우선하고 임의의 input state를 만들지 않는다.
