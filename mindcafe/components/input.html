For AI

AI Guidance

Atommerce text-field는 Figma에 확인된 property만 사용한다. - state: Default | hover | filled | auto-focused | focused | error | disabled - Trailing-type: none | btn_ghost | unit | icon - size: lg | md | sm - label / requiredMark / leadingIcon / bottomLine / helperText / charCounter는 optional property로 취급한다. - Figma에 없는 state, size, trailing type을 임의로 추가하지 않는다. - 실제 코드 API가 확인되기 전에는 Figma property 이름을 서비스 코드 API로 단정하지 않는다.
