Design intent

디자인 의도

확인, 선택, 중요한 정보 전달을 위한 기본 Modal 구조입니다.

Structure

구조 / Properties

RoleDialog surface + content + actions
Behavior현재 작업 흐름 위에서 중요한 결정을 요구
AccessibilityFocus management / dialog semantics
Design token

Design Token

정확한 토큰 값은 해당 컴포넌트의 Figma / Registry에 문서화된 값만 사용합니다.
Spacing

Spacing

Spacing은 문서화된 semantic spacing token을 우선 사용합니다. 정확한 값이 없는 경우 임의 값을 생성하지 않습니다.
Radius

Radius

Radius는 해당 컴포넌트에 정의된 semantic radius token을 사용합니다.
Typography

Typography

Typography는 UI 역할에 맞는 Component / Body / Title semantic style을 사용합니다.
Behavior

State / Behavior

  • 사용자의 흐름을 중단할 만큼 중요한 확인이나 선택에만 사용합니다.
  • Title은 사용자가 결정해야 할 내용을 직접적으로 표현합니다.
  • Primary/Secondary action의 위계를 명확히 구분합니다.
Accessibility

Accessibility

dialog semantics, focus trap, 닫기 동작, 키보드 접근성을 유지합니다.

For AI

AI Guidance

Modal은 중요한 확인·선택에만 사용한다. Title에서 사용자가 내려야 할 결정을 명확히 설명한다. Primary action은 하나만 강조한다. 닫기/취소 동작과 keyboard focus 처리를 포함한다.
