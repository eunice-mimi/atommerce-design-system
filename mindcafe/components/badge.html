Design intent

디자인 의도

Figma Core library에 존재하는 badge를 문서화한 기본 구현입니다.

Structure

구조 / Properties

RoleStatus / Label
Behavior짧은 상태 정보를 보조적으로 표시
Content짧고 즉시 이해 가능한 텍스트
Design token

Design Token

정확한 토큰 값은 해당 컴포넌트의 Figma / Registry에 문서화된 값만 사용합니다.
Spacing

Spacing

Spacing은 문서화된 semantic spacing token을 우선 사용합니다. 정확한 값이 없는 경우 임의 값을 생성하지 않습니다.
Radius

Radius

Radius는 해당 컴포넌트에 정의된 semantic radius token을 사용합니다.
Typography

Typography

Typography는 UI 역할에 맞는 Component / Body / Title semantic style을 사용합니다.
Behavior

State / Behavior

  • 짧은 상태 또는 분류 정보를 표현합니다.
  • 긴 문장이나 주요 CTA를 Badge로 표현하지 않습니다.
  • 색상만으로 의미를 전달하지 않고 텍스트 라벨을 함께 사용합니다.
Accessibility

Accessibility

상태를 색상만으로 전달하지 않고 텍스트 의미를 함께 제공합니다.

For AI

AI Guidance

Atommerce Core Design System의 badge component를 사용한다. Badge는 상태·분류처럼 짧은 보조 정보에만 사용한다. 색상과 텍스트 의미가 일치해야 한다. 새로운 Badge color를 임의로 만들지 않는다.
