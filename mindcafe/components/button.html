Behavior


State / Behavior








    

  • Primary는 현재 맥락에서 가장 중요한 핵심 행동에 사용합니다.
    • 

  • Secondary는 Primary보다 낮은 위계의 보조 행동에 사용합니다.
    • 

  • Tertiary는 중립적이거나 반복적인 보조 행동에 사용합니다.
    • 

  • Destructive 계열은 삭제, 해제 등 위험 행동에 사용합니다.
    • 

  • 동일한 결정 맥락에서 Primary CTA를 여러 개 경쟁시키지 않습니다.
    • 







State Rules


    

  • hover는 Default보다 한 단계 깊은 surface token을 사용합니다.
    • 

  • pressed는 hover보다 한 단계 더 깊은 surface를 사용합니다.
    • 

  • loading은 pressed surface + compact indicator 구조를 사용합니다.
    • 

  • disabled는 hierarchy보다 neutral disabled 체계를 우선합니다.
    • 

  • SDK on/off는 시각 스타일을 변경하지 않습니다.
    •

For AI


AI Guidance






Atommerce Core Design System의 Button을 사용한다.

- size는 lg | md | sm 중 하나를 사용한다.
- hierarchy는 primary | secondary | tertiary | destructive | destructive-tint 중 하나를 사용한다.
- hover / pressed / loading / disabled는 Registry의 state token을 그대로 따른다.
- Button size와 Component typography size는 함께 변경한다.
- semantic token을 raw HEX보다 우선한다.
- Figma에 정의되지 않은 Button variant를 임의로 생성하지 않는다.
- SDK on/off는 시각 스타일을 변경하지 않는다.
