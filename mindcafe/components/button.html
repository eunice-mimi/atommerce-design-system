Usage

Usage guidance

Atommerce Button의 hierarchy별 사용 목적, 배치 우선순위, 여러 버튼을 함께 사용할 때의 레이아웃 규칙은 현재 확인된 Figma 정보에 포함되어 있지 않습니다. 따라서 원티드 Montage의 Usage / Application / Hierarchy 규칙을 그대로 가져오지 않았습니다.
Code

Code mapping

현재 실제 서비스 코드와 Figma Button 간 Code Connect / API 매핑은 확인되지 않았습니다. 따라서 임의의 컴포넌트 API는 문서에 추가하지 않습니다.
