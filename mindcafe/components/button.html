For AI

AI Guidance

Atommerce Button은 Figma에 정의된 property와 state만 사용한다. - size: lg | md | sm - hierarchy: primary | secondary | tertiary | destructive | destructive-tint - state: Default | hover | pressed | loading | disabled - SDK: off | on - leadingIcon? / trailingIcon?은 optional property로 취급한다. - SDK on/off에 따른 시각 차이를 만들지 않는다. - Figma에 없는 Button variant, size, hierarchy, state를 임의로 추가하지 않는다. - 실제 코드 API가 확인되기 전까지 Figma property 이름을 코드 API로 단정하지 않는다.
