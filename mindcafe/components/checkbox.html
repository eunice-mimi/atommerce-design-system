Component

Checkbox

Figma Core library의 checkbox component를 기준으로 선택 상태와 접근 가능한 HTML 구조를 제공합니다.

↗
Figma component: checkboxUnchecked / Checked / Disabled

HTML

<label class="ds-check">
  <input type="checkbox" />
  <span class="ds-check-box" aria-hidden="true">✓</span>
  <span class="ds-check-text">선택 항목</span>
</label>

CSS

.ds-check input:checked + .ds-check-box {
  background: var(--comp-style-primary-default-500);
  border-color: var(--comp-style-primary-default-500);
}

.ds-check-box {
  width: 20px;
  height: 20px;
  border-radius: 6px;
}
Design intent

디자인 의도

Figma Core library의 checkbox component를 기준으로 선택 상태와 접근 가능한 HTML 구조를 제공합니다.

Structure

구조 / Properties

RoleControl · Label
StateUnchecked · Checked · Disabled
Behavior독립 선택 또는 동의 항목에 사용
Design token

Design Token

정확한 토큰 값은 해당 컴포넌트의 Figma / Registry에 문서화된 값만 사용합니다.
Spacing

Spacing

Spacing은 문서화된 semantic spacing token을 우선 사용합니다. 정확한 값이 없는 경우 임의 값을 생성하지 않습니다.
Radius

Radius

Radius는 해당 컴포넌트에 정의된 semantic radius token을 사용합니다.
Typography

Typography

Typography는 UI 역할에 맞는 Component / Body / Title semantic style을 사용합니다.
Behavior

State / Behavior

  • 복수 선택이 가능한 옵션에 사용합니다.
  • 라벨 영역 전체를 클릭 가능하게 구성합니다.
  • 필수 동의는 문구와 상태를 명확하게 표현합니다.
  • 단일 선택에는 Checkbox 대신 Radio 사용을 고려합니다.
Accessibility

Accessibility

체크 컨트롤과 label을 연결하고 키보드 포커스 및 disabled 상태를 유지합니다.

For AI

AI Guidance

Atommerce Core Design System의 checkbox component를 사용한다. 체크 상태는 색상뿐 아니라 명확한 check mark로 표현한다. label과 checkbox를 하나의 클릭 영역으로 묶는다. 복수 선택에는 Checkbox, 단일 선택에는 Radio를 우선한다.
