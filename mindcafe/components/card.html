Design intent

디자인 의도

Core library의 card / general card 계열을 사용할 때 공통적으로 필요한 구조를 정리합니다.

Structure

구조 / Properties

RoleSurface · Content · Action
Behavior관련 정보를 하나의 정보 단위로 그룹화
Interaction필요한 경우 카드 또는 내부 Action을 클릭
Design token

Design Token

정확한 토큰 값은 해당 컴포넌트의 Figma / Registry에 문서화된 값만 사용합니다.
Spacing

Spacing

Spacing은 문서화된 semantic spacing token을 우선 사용합니다. 정확한 값이 없는 경우 임의 값을 생성하지 않습니다.
Radius

Radius

Radius는 해당 컴포넌트에 정의된 semantic radius token을 사용합니다.
Typography

Typography

Typography는 UI 역할에 맞는 Component / Body / Title semantic style을 사용합니다.
Behavior

State / Behavior

  • 하나의 주제나 객체에 대한 정보를 묶을 때 사용합니다.
  • 카드 전체가 클릭 가능한지, 내부 CTA만 클릭 가능한지 명확히 결정합니다.
  • 카드 안에 너무 많은 서로 다른 행동을 넣지 않습니다.
Accessibility

Accessibility

클릭 가능한 영역과 내부 Action의 역할이 충돌하지 않도록 semantic structure를 유지합니다.

For AI

AI Guidance

Atommerce Core Design System의 card 또는 general card를 우선 사용한다. Card는 하나의 정보 단위를 묶는 container로 사용한다. 내부 action hierarchy를 명확하게 유지하고 CTA를 과도하게 배치하지 않는다. 정의된 Card variant가 있다면 새로운 surface style을 임의 생성하지 않는다.
