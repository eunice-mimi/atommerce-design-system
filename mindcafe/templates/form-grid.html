Form Grid

레퍼런스의 입력 + 요약 구조처럼, 폼을 좌우 영역으로 나눠 탐색성과 완료 행동을 강화하는 템플릿입니다.

↗
신청 정보
선택한 옵션과 금액 등 요약 정보를 노출합니다.

HTML

<div class="form-grid">
  <main class="form-grid__fields">...</main>
  <aside class="form-grid__summary">...</aside>
</div>

CSS

.form-grid {
  display: grid;
  grid-template-columns: minmax(0, 2fr) minmax(260px, 1fr);
  gap: 24px;
}

  .form-grid { grid-template-columns: 1fr; }
}
Design intent

디자인 의도

레퍼런스의 입력 + 요약 구조처럼, 폼을 좌우 영역으로 나눠 탐색성과 완료 행동을 강화하는 템플릿입니다.

Structure

구조 / Properties

CompositionForm area + Summary / CTA area
LayoutDesktop 2-column → Mobile 1-column
Behavior긴 입력 흐름과 요약/결제 영역을 분리
Design token

Design Token

정확한 토큰 값은 해당 컴포넌트의 Figma / Registry에 문서화된 값만 사용합니다.
Spacing

Spacing

Spacing은 문서화된 semantic spacing token을 우선 사용합니다. 정확한 값이 없는 경우 임의 값을 생성하지 않습니다.
Radius

Radius

Radius는 해당 컴포넌트에 정의된 semantic radius token을 사용합니다.
Typography

Typography

Typography는 UI 역할에 맞는 Component / Body / Title semantic style을 사용합니다.
Behavior

State / Behavior

Structure

  • 주 입력 영역과 요약/CTA 영역을 2열로 분리합니다.
  • 좁은 화면에서는 1열로 쌓습니다.
  • 요약 영역은 사용자가 입력 내용을 확인하고 행동을 완료하는 역할을 합니다.
Accessibility

Accessibility

입력 순서와 시각적 배치가 달라도 키보드 탐색 순서는 논리적으로 유지합니다.

For AI

AI Guidance

Form Grid Template은 Atommerce Form Pattern과 Card, Button을 조합한다. Desktop에서는 입력과 요약 영역을 2열로 배치한다. Mobile에서는 1열로 쌓는다. Sticky CTA가 필요하면 요약 영역의 맥락을 유지한다.
