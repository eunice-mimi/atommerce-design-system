Usage rules

Semantic token 우선

제품 화면에서는 sys/* 또는 comp/*를 사용합니다. ref/*는 색상의 원천값을 정의할 때 사용합니다.

서비스별 hex 하드코딩 금지

MindCafe, Tarotbom, Admin, Expert의 Primary가 달라도 token name을 유지하고 Figma mode를 통해 값을 분리합니다.

State는 Component token 사용

Default / Hover / Pressed / Disabled처럼 상태가 있는 UI는 각 컴포넌트 문서의 comp/style/*, comp/cont/* 규칙을 따릅니다.

확인되지 않은 토큰은 만들지 않기

현재 Figma Color Token 컬렉션에 없는 이름이나 값은 임의로 추가하지 않습니다. 필요한 경우 디자인 시스템에 먼저 정의합니다.

참고: Center Console은 현재 이 Color Token 컬렉션에서 별도의 mode 이름으로 확인되지 않았습니다. Center 전용 색상 규칙은 별도 라이브러리/자산 확인 후 문서화합니다.
