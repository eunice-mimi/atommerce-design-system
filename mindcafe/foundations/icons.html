Icons

인터페이스의 기능과 상태를 빠르게 인지할 수 있도록 사용하는 아이콘 자산입니다. 이 페이지는 Atommerce Core Design System에서 확인된 아이콘을 기준으로 구성합니다.

Basic icons

Core Library에 등록된 기본 아이콘 컴포넌트입니다. 로고 자산은 별도 Logo 문서에서 관리합니다.

20 icons

Custom icons

Core Design System의 Custom icon 영역은 Gradient Type과 Flat Type으로 구분되어 있습니다.

Gradient Type

브랜드 컬러와 다중 색상을 사용하는 커스텀 아이콘.

Flat Type

단색 또는 제한된 색상으로 구성된 커스텀 아이콘.
