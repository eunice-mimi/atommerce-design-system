Claude Code Skill

한 번 설치하면 Claude Code가 Atommerce Design System의 공통 디자인 정책을 항상 참고할 수 있습니다. Skill은 실행할 때 배포된 사이트의 /llms.txt를 기준으로 최신 문서를 확인하도록 구성합니다.

1. 설치

아래 명령은 배포된 도메인을 기준으로 자동 생성됩니다.

Terminal
curl -fsSL https://atommerce-design-system.vercel.app/skill/SKILL.md -o ~/.claude/skills/atommerce-design-system/SKILL.md

2. 사용 예시

Atommerce 디자인 시스템을 사용해서 상담 신청 폼을 만들어줘. Button, Input, Typography는 디자인 시스템 문서를 따라줘.
디자인 시스템 사이트의 token / component / template 문서가 바뀌어도 /llms.txt가 최신 경로를 가리키도록 유지하면 AI가 최신 구조를 참고할 수 있습니다.

Skill에 들어가는 정책

  • semantic token 우선 사용
  • 정의되지 않은 variant / token 임의 생성 금지
  • Title / Body / Component Typography 역할 구분
  • Primary / Secondary / Tertiary / Destructive 행동 위계
  • 기존 Component → Pattern → Template 우선 재사용
  • 문서에 없는 정책이 필요하면 사용자에게 먼저 확인

웹에서 사용할 Skill 파일

아래 주소의 SKILL.md가 Atommerce 공통 디자인 정책 파일입니다. 웹 환경에서 Skill 파일을 등록하거나 프로젝트 지침으로 연결할 때 이 파일을 사용합니다.

https://atommerce-design-system.vercel.app/skill/SKILL.md
