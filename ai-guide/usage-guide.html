AI Guide

Usage Guide

AI가 화면을 생성하거나 수정할 때 적용해야 하는 공통 규칙입니다.

Do

Semantic token 사용
기존 component variant 재사용
문서화된 typography hierarchy 유지
Pattern / Template 우선 참고

Don't

임의 HEX 생성
정의되지 않은 Button variant 생성
Typography 역할 혼용
없는 규칙을 추정해서 추가

AI Context

Atommerce Design System을 source of truth로 사용한다. semantic token을 raw value보다 우선한다. Registry에 없는 variant를 임의 생성하지 않는다. Foundation → Component → Pattern → Template 순서로 관련 규칙을 확인한다. 문서에 없는 규칙이 필요하면 사용자에게 먼저 확인한다.

추천 사용 흐름

  1. 사용 중인 Claude Code 환경에 Atommerce Design System Skill을 등록합니다.
  2. 필요한 Button / Input / Template 상세 페이지를 엽니다.
  3. Copy for AI를 눌러 페이지 전체 컨텍스트를 복사합니다.
  4. Claude Code에 붙여넣고 만들고 싶은 화면을 요청합니다.
  5. Skill 등록 후에는 `https://atommerce-design-system.vercel.app/button.html` 같은 상세 페이지 URL을 함께 전달해 사용할 수 있습니다.
